# Zamorano · Delegación Europa 2026 — Presentación

Presentación interactiva (sitio web autocontenido en un solo archivo HTML) sobre la nueva era tecnológica —datos, automatización, robótica, biotecnología y conectividad, aceleradas por la inteligencia artificial— y su relevancia para el agro y para la Universidad Zamorano.

## Archivos

- **`Zamorano_Presentacion.html`** — La presentación final. Ábrela en cualquier navegador (Chrome recomendado).
- **`assets/`** — Ilustraciones vectoriales y espacio para fotos del viaje (ver `assets/LEEME-imagenes.txt`).

## Uso

Abre `Zamorano_Presentacion.html` en el navegador. Navegación:

- **← →** o barra espaciadora: avanzar / retroceder
- **M**: menú de slides
- **F**: pantalla completa
- También funciona con clic en las flechas, los puntos laterales y deslizando en móvil

No requiere internet para funcionar (los logos de empresas se cargan de la web si hay conexión; si no, se muestran íconos de marca incrustados).
